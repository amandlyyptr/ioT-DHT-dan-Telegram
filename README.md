# IoT Monitoring & Telegram Notification

Project monitoring data sensor menggunakan perangkat IoT dengan fitur notifikasi otomatis melalui Telegram. Project ini mencakup monitoring data sensor serta perancangan rangkaian perangkat.

# Fitur

- Monitoring data sensor
- Pembacaan data sensor secara berkala
- Menampilkan data hasil pembacaan sensor
- Notifikasi otomatis melalui Telegram
- Perancangan rangkaian perangkat IoT

# Tools & Teknologi

- IoT
- Sensor
- Telegram Bot
- Mikrokontroler

# Cara Menjalankan

1. Clone repositori ini
2. Siapkan perangkat dan rangkaian IoT
3. Hubungkan sensor dengan mikrokontroler
4. Konfigurasi Telegram Bot
5. Jalankan program pada perangkat
6. Pantau data sensor dan notifikasi melalui Telegram

## Hasil

Sistem dapat melakukan monitoring data sensor dan mengirimkan notifikasi secara otomatis melalui Telegram berdasarkan data yang diperoleh dari sensor.
